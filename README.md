# 献立ルーレット（menuroulette）

「今日のごはん、何にしよう」をランダムに決めるための汎用献立ツールです。内蔵の献立リスト（約45品）から抽選します。キャラクター要素のない、シンプルな道具です。

## 使い方

- **3品セット**：主菜＋副菜＋汁物をセットで抽選します。
- **主菜だけ1品**：主菜のみを抽選します。
- **系統フィルタ**：和／洋／中を指定すると、その系統の中から抽選します（指定なしは全体から）。
- **直近3回の主菜を避ける**：チェックを入れると、履歴にある直近3回の主菜を候補から外して抽選します（候補が尽きる場合は通常抽選に戻ります）。
- **自作の献立**：料理名・区分（主菜／副菜／汁物）・系統を登録すると抽選候補に加わります。削除もできます。
- 抽選結果は履歴に JST 時刻つきで保存され、一覧で見返せます。

データは SQLite に保存されます。DB のパスは環境変数 `MENUROULETTE_DB` で変更できます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- レシピや作り方は表示しません。献立名を決めるだけのツールです。
- 抽選は完全なランダム（「直近を避ける」併用時を除く）で、栄養バランスや在庫食材は考慮しません。
- 内蔵リストは約45品の固定リストです。増やすには自作追加か `app.py` の編集が必要です。
- ログイン機能はありません。Render 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。
